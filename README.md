# Journey Demo CRM

A small demo CRM for fictional callers. It supports:

- Creating and editing caller records
- Storing the Infinity prompt session flags
- Storing the `demoData.esdc` benefit reference fields
- Journey Customers Lookup
- Journey SMS digital-authentication execution requests
- Receiving a Journey callback and correlating its documented identifiers
- Operator review before marking authentication confirmed for this demo

## Local run

Requires Node.js 20 or newer.

npm install
